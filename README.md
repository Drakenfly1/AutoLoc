# AutoLoc

## Acteurs et cas d'utilisation

Le système AutoLoc fait intervenir quatre acteurs principaux :

| Acteur | Cas d'utilisation |
|---|---|
| **Client** | Consulter les véhicules disponibles, rechercher un véhicule, effectuer une réservation, modifier une réservation, annuler une réservation, consulter ses réservations |
| **Agent d'agence** | Gérer les réservations, gérer les prises en charge et les retours, consulter les véhicules disponibles, consulter les informations des clients |
| **Responsable d'agence** | Gérer le parc automobile, gérer les agents, superviser les réservations, consulter les statistiques de l'agence |
| **Administrateur** | Gérer les utilisateurs, gérer les agences, gérer les comptes et administrer le système |

## Technologies

- **Java 17**
- **Spring Boot 4.0.8**
- **Maven**
